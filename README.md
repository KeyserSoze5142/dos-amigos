# Dos Amigos Mexican Grill — website

Static multi-page site for www.dosamigosmexicangrill.com, hosted on GitHub Pages.

```
index.html              Home
menu/index.html         Full menu (8 sections, Menu schema)      → /menu/
specials/index.html     Lunch specials + daily specials          → /specials/
hours-location/index.html  Hours, map, directions, FAQ          → /hours-location/
gallery/index.html      Photo gallery (ImageGallery schema)      → /gallery/
404.html                Custom not-found page
assets/style.css        Shared styles
assets/main.js          Shared script (menu tabs, mobile nav, today's hours/special)
images/                 Real dish photos (JPG + WebP, 2 sizes each)
sitemap.xml, robots.txt, CNAME
```

To update menu prices edit `menu/index.html` (and the matching lunch items in `specials/index.html`).
